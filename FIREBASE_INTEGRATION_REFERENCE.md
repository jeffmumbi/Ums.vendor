### FirebaseDataBridge Methods

Use these in your application (hybrid storage with fallback):

```javascript
// Issues
const issues = await FirebaseDataBridge_Instance.getIssues();
const issue = await FirebaseDataBridge_Instance.saveIssue(issueData);
await FirebaseDataBridge_Instance.deleteIssue(issueId);

// Passwords
const passwords = await FirebaseDataBridge_Instance.getPasswords();
const pwd = await FirebaseDataBridge_Instance.savePassword(pwdData);
await FirebaseDataBridge_Instance.deletePassword(pwdId);

// Documents
const docs = await FirebaseDataBridge_Instance.getDocuments();
const doc = await FirebaseDataBridge_Instance.saveDocument(docData);
await FirebaseDataBridge_Instance.deleteDocument(docId);

// Incidents
const incidents = await FirebaseDataBridge_Instance.getIncidents();
const incident = await FirebaseDataBridge_Instance.saveIncident(incidentData);
await FirebaseDataBridge_Instance.deleteIncident(incidentId);

// Notifications
const notif = await FirebaseDataBridge_Instance.addNotification(notifData);
const notifications = await FirebaseDataBridge_Instance.getNotifications(50);
await FirebaseDataBridge_Instance.clearNotifications();

// Check status
const status = FirebaseDataBridge_Instance.getStatus();
console.log(status);
// Output: { usingFirebase: true, isSyncing: false, queueLength: 0 }
```

## Integration Examples

### Example 1: Save Issue with Error Handling
```javascript
async function saveIssueWithFirebase(issueData) {
    try {
        const result = await FirebaseDataBridge_Instance.saveIssue(issueData);
        console.log('Issue saved:', result.id);
        showToast('Issue saved successfully!');
        return result;
    } catch (error) {
        console.error('Failed to save issue:', error);
        showToast('Error saving issue: ' + error.message);
        return null;
    }
}
```

### Example 2: Load and Display Issues
```javascript
async function loadIssuesFromFirebase() {
    try {
        const issues = await FirebaseDataBridge_Instance.getIssues();
        const html = issues.map(issue => `
            <tr>
                <td>${issue.vendor}</td>
                <td>${issue.system}</td>
                <td>${issue.status}</td>
            </tr>
        `).join('');
        document.getElementById('issuesTable').innerHTML = html;
    } catch (error) {
        console.error('Failed to load issues:', error);
    }
}
```

### Example 3: Check Firebase Status
```javascript
function checkFirebaseConnection() {
    const status = FirebaseDataBridge_Instance.getStatus();
    if (status.usingFirebase) {
        console.log('✅ Connected to Firebase');
    } else {
        console.log('ℹ️ Using local storage (offline mode)');
    }
}
```

### Example 4: Migrate from LocalStorage
```javascript
async function migrateDataToFirebase() {
    try {
        const localData = {
            issues: JSON.parse(localStorage.getItem('issues') || '[]'),
            passwords: JSON.parse(localStorage.getItem('passwords') || '[]'),
            incidents: JSON.parse(localStorage.getItem('incidents') || '[]')
        };
        
        const success = await FirebaseService.migrateFromLocalStorage(localData);
        if (success) {
            showToast('Data migrated to Firebase!');
        }
    } catch (error) {
        showToast('Migration failed: ' + error.message);
    }
}
```

## Firestore Security Rules

### Production Rules (Recommended)
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Only authenticated users
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

### Admin-Only Collections
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Everyone can read users
    match /users/{document=**} {
      allow read: if true;
      // Only admins can write
      allow write: if get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'Admin';
    }
    
    // Only authenticated users
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

## Storage Security Rules

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // Documents folder - authenticated users only
    match /documents/{allPaths=**} {
      allow read, write: if request.auth != null;
    }
    
    // Deny everything else
    match /{allPaths=**} {
      allow read, write: if false;
    }
  }
}
```

## Performance Tips

1. **Batch Operations**: Use `batch.commit()` for multiple writes
2. **Indexes**: Create composite indexes for complex queries
3. **Pagination**: Load data in smaller chunks
4. **Caching**: Keep frequently accessed data in memory
5. **Offline**: Enable offline persistence in config

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| "Permission denied" | Check Firestore Rules, ensure user is logged in |
| "Document not found" | Verify document ID is correct string format |
| "Too many requests" | Implement exponential backoff retry |
| "Large file upload fails" | Check Storage bucket quota, increase if needed |
| "Real-time updates slow" | Optimize Firestore query, add indexes |
